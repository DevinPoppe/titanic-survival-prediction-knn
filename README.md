# Titanic Survival Prediction using KNN

This project explores the Titanic dataset to predict passenger survival using a **K-Nearest Neighbors** classifier. It covers the entire data science workflow, from data cleaning and feature engineering to model optimization and evaluation. 

## 🔍 Project Overview
The goal of this project is to analyze which factors influenced a passenger's chance of survival and to build a machine learning model that predicts survival based on features like age, class, gender and family size. 


##  🛠️ Key Features
* **Data Cleaning** 
* **Feature Enineering**
* **Exploratory Data Analyisis**
* **Machine Learning**
* **Evaluation**

## 📊 Results

* **Optimal k:** The model achieved its best performance around k=15
* **Accuracy:** ~84.75% on the test set.
* **Insight:** The model is highly accurate at predicting non-survivor but shows room for improvment in identifying survivors (due to class imbalance.)
